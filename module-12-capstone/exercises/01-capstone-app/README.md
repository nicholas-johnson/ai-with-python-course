# Exercise 01 — Capstone app

**Mission briefing:** Build the full integrated Pathfinder experience — conversational entrypoint, retrieval over ship documents or data, MCP-exposed tools, and a multi-agent branch for complex analysis.

## Objectives

1. Wire chat (CLI or minimal web) to your orchestration layer.
2. Add RAG (or structured retrieval) over at least one corpus (logs, manuals, mission briefs).
3. Expose and call multiple MCP tools; use a supervisor or router for multi-agent steps.

pytest module-12-capstone/exercises/01-capstone-app/test_start.py -v
