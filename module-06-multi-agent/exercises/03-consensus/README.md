# Exercise 03 — Consensus

**Mission briefing:** Multiple agents propose answers to the same Pathfinder question. Implement a voting or scoring step to pick the response surfaced to the user.

## Objectives

1. Run N agent stubs (or prompts) in parallel or sequence to get proposals.
2. Apply a deterministic selection rule (vote, rank, tie-break).
3. Log dissenting opinions for ops review.
