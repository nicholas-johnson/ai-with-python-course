# Navigation Manual — DSS Pathfinder

## Coordinate System

The ship uses a galactic coordinate system with three axes:
- **X**: Galactic longitude (light-years from Sol)
- **Y**: Galactic latitude (light-years from galactic plane)
- **Sector**: Named grid square (e.g., Sol-A, Alpha-1, Lyra-7)

## Course Plotting

1. Enter origin and destination in the nav console.
2. System calculates heading (degrees), distance (light-years), and ETA.
3. ETA assumes standard cruise speed of 5 ly/hour.
4. Review plotted course for anomalies or hazards before engaging.

## Sensor Calibration

Sensors should be calibrated every 72 hours or after any of:
- Warp drive activation/deactivation
- Passage through a nebula or radiation belt
- Power grid fluctuation exceeding 15%

Calibration procedure: Run diagnostic from Engineering Console > Sensors > Full Calibration. Takes approximately 20 minutes.
