# Emergency Procedures — DSS Pathfinder

## Alert Levels

- **Green**: Normal operations. All systems nominal.
- **Yellow**: Elevated caution. Non-essential personnel report to quarters.
- **Red**: Immediate danger. All hands to emergency stations.
- **Black**: Catastrophic failure. Evacuation authorised.

## Evacuation Routes

1. **Primary**: Deck corridors to escape pods (Sections A1-A8).
2. **Secondary**: Service tunnels to shuttle bay (Deck 4).
3. **Emergency**: Hull breach shelters (every 50 meters, marked in orange).

## Hull Breach Protocol

1. Seal affected section (automatic or manual override).
2. Activate emergency atmosphere in adjacent sections.
3. Confirm all personnel accounted for via biometric scan.
4. Engineering team assesses structural integrity before re-entry.
