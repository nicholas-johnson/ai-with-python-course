# Crew Handbook — DSS Pathfinder

## Chain of Command

1. **Captain**: Commander Elara Voss
2. **First Officer**: Lt. Commander Riku Tanaka
3. **Department Heads**: Chief Engineer, Chief Science Officer, Chief Medical Officer
4. **Senior Officers**: Lieutenants and Specialists
5. **Junior Officers**: Ensigns

## Duty Rosters

Standard rotation is three 8-hour shifts:
- **Alpha shift** (0600–1400): Primary operations crew
- **Beta shift** (1400–2200): Secondary operations crew
- **Gamma shift** (2200–0600): Overnight skeleton crew

Shift changes require a 15-minute handover briefing.

## Communication Protocols

- **Routine**: Use department comm channels (CH-1 through CH-10).
- **Priority**: Use the bridge channel (CH-0) for urgent matters.
- **Emergency**: Activate ship-wide broadcast via any comm panel.
- **External**: All external communications must be logged and approved by the Captain.

## Leave and Recreation

- Crew members receive one rest day per standard week.
- Recreation facilities: gym (Deck 3), observation lounge (Deck 1), library (Deck 2).
- Shore leave is granted at the Captain's discretion during station stops.
